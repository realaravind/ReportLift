## Challenges Addressed

1. **RDL Namespace Variations**
   - Different SSRS versions use different namespaces
   - Implemented flexible namespace handling with lxml

2. **Scoring Calibration**
   - Initial weights were too aggressive
   - Tuned penalties based on real-world report samples

3. **Expression Complexity Classification**
   - RunningValue, Previous, and Lookup expressions are nuanced
   - Built comprehensive pattern library for accurate categorization
