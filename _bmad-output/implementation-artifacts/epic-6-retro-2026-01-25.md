## Challenges Addressed

1. **Prompt Engineering**
   - Initial prompts produced inconsistent SQL
   - Refined with explicit output format requirements
   - Added validation step for generated SQL

2. **Timeout Management**
   - Complex SPs can take long to analyze
   - 60-second default timeout with graceful cancellation
   - Background task prevents UI blocking

3. **Confidence Calibration**
   - AI confidence doesn't always match reality
   - Added SQL validation step to adjust confidence
